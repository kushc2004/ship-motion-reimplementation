# Ship-motion reusable artifacts

This Kaggle Dataset is the persistent cache for outputs generated by the
leakage-free ship-motion benchmark. It must contain only the contents of the
Kaggle notebook's `ship-motion-artifacts/` directory.

The notebook restores this dataset before running. It reuses a stage only when
all required files exist and the primary artifact's recorded M0--M2 hashes
still match the checked-in immutable inputs. Partial files, stale artifacts,
or changed inputs cause that stage to rerun. At the end of a Kaggle run, either
save the notebook output and update this Dataset locally, or (when Kaggle CLI
credentials are available in that session) run the commented `datasets version`
command in the notebook.

Upload/update from a machine with authenticated Kaggle CLI:

```bash
kaggle datasets create -p kaggle_artifact_store
# Later, populate this directory with the downloaded ship-motion-artifacts/
# contents, then:
kaggle datasets version -p kaggle_artifact_store --message "benchmark artifacts"
```

Do not add raw datasets, credentials, or unverified/partial benchmark outputs.
